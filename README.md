# lp-rv32-mcu (work in progress)

A power-managed RISC-V microcontroller (RV32I + Zicsr + Zbb, UART, timer, GPIO, PMU), taken from RTL to GDS
on SKY130. This replaces the original single-cycle 4-bit core, which is now kept in [`legacy/`](legacy/)
and audited in [`docs/AUDIT.md`](docs/AUDIT.md).

- Spec: [`docs/BRIEF.md`](docs/BRIEF.md)
- Status: [`PROGRESS.md`](PROGRESS.md)
